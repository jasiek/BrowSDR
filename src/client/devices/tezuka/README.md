# Tezuka (network)

BrowSDR connects to PlutoSDR-class boards running [Tezuka firmware](https://github.com/F5OEO/tezuka_fw) over the local network, with no USB driver. Open **Add SDR**, enter the board's host name or IP address (default `pluto.local`) and press **Connect**. Any browser with WebSockets works, including ones without WebUSB.

- **Control:** MQTT over WebSocket to the firmware's Mosquitto (`/mqtt` on port 9001, or 9002 with TLS). BrowSDR publishes `cmd/rx/frequency`, `cmd/rx/sampling`, `cmd/rx/bandwidth`, `cmd/rx/gain_mode` and `cmd/rx/gain`, and reads the retained `state/...` and `state/caps/...` topics for confirmations and ranges. Connecting turns off Tezuka's spectrum sweep, which otherwise hops the LO.
- **IQ:** the firmware's `iio_ws_proxy` (port 8765, or 8766 with TLS, subprotocol `iio-rx`) sends RX1 as 12-bit samples in 16-bit words. BrowSDR starts it with `cmd/system/iqtape` when it is off, and stops it on disconnect only if BrowSDR started it. The proxy serves one receiver at a time, so stop **IQ Tape** or the **Radio** page in the Tezuka dashboard first.
- **HTTPS pages:** a page served over `https://` cannot open plain `ws://` sockets unless the browser exempts local network hosts. BrowSDR tries `ws://` first and falls back to the TLS ports, which use the board's self-signed certificate: open `https://pluto.local/` once in the same browser and accept it. Allow local network access if the browser asks.
- **Sample rates:** each sample takes 4 bytes. A 100 Mbit/s link carries about 2.9 MSPS over `ws://`. TLS encryption on the Zynq CPU limits `wss://` to about 1.8 MSPS on a PlutoSky, below the 2.4 MSPS minimum, so expect dropped buffers over TLS. Shortfalls are logged as browser console warnings. For gap-free reception, open BrowSDR over `http://` (for example a local `npm run dev`) or from a browser that allows `ws://` to local hosts.
- **Slow first connection on macOS:** `pluto.local` takes about 5 seconds to resolve the first time, because the board does not answer mDNS IPv6 queries. Use its IP address to avoid the wait.
